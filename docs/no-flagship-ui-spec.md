# No-flagship lab — UI specification

## Цель
Экран должен восприниматься прежде всего как большая игровая карта. HUD лежит поверх карты, а не отнимает у неё отдельные пустые зоны.

## Карта и масштаб
- По умолчанию карта масштабируется почти на всю ширину/высоту landscape-экрана.
- Допускается, что крайние острова и части карты слегка уходят под верхний HUD, Тайный путь или правую область интерфейса.
- Перекрытие считается допустимым: любой остров должен оставаться доступен после pinch-to-zoom и drag.
- Минимальный масштаб — стартовый; максимальный — 2.6x.
- После увеличения карту можно перетаскивать. Drag не должен случайно выбирать остров.
- При новом запуске и смене размера экрана карта возвращается к центрированному стартовому виду.

## Порядок освоения
- В фазе освоения нет большой панели очереди.
- Справа поверх карты находится компактный вертикальный столбик из 6 строк — по одной строке на каждый раунд освоения.
- В каждой строке маленькие цветные прямоугольники показывают фактический порядок захватов этого раунда.
- Так как первые два игрока раунда получают второй захват, строка содержит 6 отметок.
- Текущий раунд показывается ярко; завершённые раунды приглушаются.
- Текущий захват выделяется светлой обводкой/свечением.
- Никаких имён, номеров или фоновых карточек в режиме освоения.

## Порядок войны
- После перехода к войне справа возвращается вертикальная текстовая очередь текущего раунда.
- Текущий игрок выделен, уже сходившие приглушены.

## HUD
- Дублоны — слева сверху.
- Фаза/раунд и статус — сверху по центру.
- Слава — справа сверху.
- Тайный путь и основная кнопка действия остаются справа поверх карты.
- Флагман отсутствует во всех слоях UI и gameplay.

## Визуальные ассеты
- Используется исходный SVG-набор из коммита 126b4ffc2b7feab149cd8dce6d8c4b9a712ff82c (Pirates v1.1 illustrated map assets).
- Не применять позднее приглушение/смешивание SVG с пергаментом из коммита 8f956de4.
- Размер островов остаётся компактным: 36 территорий должны читаться как единая карта и не сливаться.

## Вопросы
- Полоса времени человека: 20 секунд.
- Правильный вариант: только зелёная светящаяся обводка, без зелёной заливки.
- Левая половина ответа — выбор атакующего, правая — выбор защитника.
- Выбранная половина заполняется цветом соответствующего игрока.
- Если оба выбрали один вариант, карточка делится 50/50 их цветами.
- Раскрытый результат остаётся видимым 3 секунды перед продолжением боя.


## Карта — Schema 1.0
- Каноническая игровая схема зафиксирована как **Map Schema 1.0**.
- Единственный источник истины по уровням островов и графу: `docs/map-schema-v1.0.md`.
- Любые визуальные ассеты карты, островов и баз должны накладываться на эту схему без изменения номеров, уровней или связей.
- Изменение схемы допускается только как новая явно пронумерованная версия (1.1, 2.0 и т. п.), а не тихой правкой текущей 1.0.
